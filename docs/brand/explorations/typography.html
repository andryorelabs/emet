Typography pairings T1-T4

Four display or UI plus mono pairings, all under the SIL Open Font License, loaded from local woff2 files in fonts/ with no network access. The wordmark is a placeholder and these are options to compare, not a decision. Each specimen shows a wordmark, a README heading with body text and terminal output. License text and upstream sources are in fonts/OFL.md.

Notes

All four files are Latin subsets, so non-Latin scripts fall back to the system font. The mono in T1 and T3 is the same family, so the choice between them is about the UI face. Terminal colors here are illustrative; the ANSI previews are on the palette sheet.
