Palette options P1-P4

Four palette options for the rename and kit run, each in light and dark with shadcn-style oklch tokens, a README mock, an ANSI 16-color terminal preview and WCAG 2.x contrast ratios. These are options for the maintainer to compare, not a decision. None uses Claude orange, clay or any Anthropic palette value; each card notes its proximity risk. Lowest ratio of every text pair and ANSI color on this sheet: 4.53:1 (AA body text needs 4.5:1).

P1 Indigo Ink

Cool blue-violet accent on blue-tinted neutrals. Reads as precise and technical.

Proximity and risk: Violet is crowded in dev tools (several editors and CI products); no Anthropic proximity. Not derived from Anthropic's or Claude's palette.

Method

Ratios are WCAG 2.x relative-luminance contrast, computed by script from the sRGB value each oklch token resolves to (chroma reduced until the colour is inside sRGB, so the browser shows the same value). Text pairs are tuned to at least 4.5:1; ANSI colors are checked against the terminal background of the same mode. The mocks use the system font stack; typefaces are on the typography sheet.
