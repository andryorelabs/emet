# How-to guides

Task-focused guides. Each one answers a single "how do I" question. Terms follow [GLOSSARY.md](../../GLOSSARY.md).

- [`mascot.md`](mascot.md): install the optional `emet-mascot` plugin, read the phase file it follows and import the Orca pet bundle.
- [`update-emet.md`](update-emet.md): update the emet and emet-mascot plugins by hand or turn on marketplace auto-update.
- [`cut-a-release.md`](../contributing/cut-a-release.md): the release runbook: version bump, changelog, develop to main PR, tag and the CI-gated release.
- [`translate.md`](../contributing/translate.md): find the Website pages that need a translation and add or refresh one.
