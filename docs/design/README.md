| Area    | Canvas                                                            | Artboards                                               |
| ------- | ----------------------------------------------------------------- | ------------------------------------------------------- |
| Website | [emet Website](https://claude.ai/artifact/PMpa6e7MSiisZSD45BjENF) | Home, Docs article, Docs search, Language switcher, 404 |
