Что такое emet, что делает запуск и куда идти дальше. Термины соответствуют [GLOSSARY.md](../../GLOSSARY.md).

<img src="../brand/mascot/mascot-done.svg" alt="маскот emet, готово" width="96" align="right">

emet доводит функциональность от идеи до слитого изменения внутри Claude Code или Codex CLI, в любом git-репозитории, с Linear, GitHub Issues или локальными тикетами. Вы описываете функциональность один раз и один раз подтверждаете спецификацию и тикеты; остальное выполняется без присмотра.

## Что делает запуск

1. `/emet:run` (`$emet:run` в Codex) проводит с вами интервью и пишет спецификацию.
2. Он разбивает спецификацию на тикеты и запрашивает одно подтверждение.
3. Параллельные воркеры реализуют каждый тикет в собственном git worktree.
4. Ревью проверяет каждую волну, а CI должен быть зелёным; всё, что помечено, останавливает слияние.
5. Спецификация по умолчанию приземляется одним pull request или локальным слиянием, и следующая волна может продолжить цепочку.
