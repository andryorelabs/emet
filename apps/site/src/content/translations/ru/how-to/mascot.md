Покажите **Маскота** emet в Claude Code и в Orca. Термины соответствуют [GLOSSARY.md](../../GLOSSARY.md).

Есть две независимые части: необязательный плагин `emet-mascot`, рисующий маскота в Claude Code, и набор питомца для Orca, который даёт Orca того же персонажа. emet не нуждается ни в одной из них.

## Предварительные требования

- Claude Code, для плагина.
- emet установлен, чтобы запуск записывал файл фазы, за которым следует маскот; см. [Установка](../start/install.md).
- Orca, для питомца. Для импорта нужна папка `docs/brand/pet/emet/` на машине, где запущено приложение Orca.

## Установка плагина маскота

:::steps

1. Добавьте маркетплейс и установите плагин:

   ```bash
   claude plugin marketplace add andryorelabs/emet
   claude plugin install emet-mascot@emet-marketplace
   ```

2. Перезапустите Claude Code. Маскот следует за вашей сессией (спит, работает, ждёт, готово, ошибка). Пока активен **Run**, он также читает файл фазы и показывает приглушённую подпись вроде `emet · wave 2 · review`.
3. При желании задайте параметры плагина:
   - `position`: `pane` (по умолчанию), `band` или `status`. `pane` закрепляет маскота рядом с транскриптом, для чего нужен полноэкранный режим и терминал шириной не менее 144 столбцов, пока вы сами один раз не откроете панель (после этого около 110); если закрепить нельзя, маскот показывается над строкой ввода. `band` всегда рисует его над строкой ввода. `status` показывает только текстовую подпись как строку состояния.
   - `size`: `small` (16 x 8 ячеек, по умолчанию) или `medium` (24 x 12 ячеек).
   - `showLabel`: показать или скрыть подпись (по умолчанию включено).

:::

## Обновление плагина маскота

У маркетплейсов, кроме маркетплейса Anthropic, автообновление по умолчанию выключено, поэтому обновляйте вручную или включите его один раз.

:::steps

1. Обновите маркетплейс и плагин:

   ```bash
   claude plugin marketplace update emet-marketplace
   claude plugin update emet-mascot@emet-marketplace
   ```

2. Перезапустите Claude Code.
3. Чтобы плагин обновлялся сам, выполните `/plugin`, откройте вкладку **Marketplaces**, выберите `emet-marketplace` и нажмите **Enable auto-update**. Каждый пользователь делает это один раз на своей машине. Об основном плагине см. [Обновление emet](update-emet.md).

:::

## Питомец в Orca

:::steps

1. Убедитесь, что `docs/brand/pet/emet/` (`pet.json` и `spritesheet.webp`) находится на машине, где запущена Orca; скопируйте папку туда, если Orca работает не там, где этот репозиторий.
2. В настройках Orca выберите «Import .codex-pet bundle…» и укажите эту папку.
3. После изменения SVG маскота пересоздайте набор командой `bun run brand:export` и закоммитьте результат.

:::

## Проверка

:::steps

1. Выполните `claude plugin list` и убедитесь, что `emet-mascot` включён; если маскота нет, перезапустите Claude Code.
2. Во время запуска убедитесь, что `.emet/phase.json` существует и обновлялся в последние несколько секунд. Маскот опрашивает его примерно раз в две секунды и игнорирует файл старше окна свежести, поэтому упавший запуск не оставляет устаревшую подпись. Файл содержит `phase` (`planning`, `dispatch`, `working`, `review`, `checking`, `landing`, `done` или `failed`), `wave`, `spec`, `runId`, `updatedAt` и необязательный `outcome`.
3. В Orca убедитесь, что питомец emet появился в списке питомцев.

:::
