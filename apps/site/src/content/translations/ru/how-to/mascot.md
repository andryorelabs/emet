Как показать **Маскота** emet в Claude Code и в Orca. Термины соответствуют [GLOSSARY.md](../../GLOSSARY.md).

Есть две независимые части: необязательный плагин `emet-mascot`, рисующий маскота в Claude Code, и набор питомца для Orca, который даёт Orca того же персонажа.

## Установка плагина маскота

Плагин поставляется в том же маркетплейсе, что и emet, и необязателен. emet в нём не нуждается.

```bash
claude plugin marketplace add andryorelabs/emet
claude plugin install emet-mascot@emet-marketplace
```

Маскот следует за вашей сессией (спит, работает, ждёт, готово, ошибка). Пока активен **Run**, он также читает **Phase file** и показывает приглушённую подпись вроде `emet · wave 2 · review`.

Параметры плагина:

- `position`: `pane` (по умолчанию), `band` или `status`. `pane` закрепляет маскота рядом с транскриптом, для чего нужен полноэкранный режим и терминал шириной не менее 144 столбцов, пока вы сами один раз не откроете панель (после этого около 110); если закрепить нельзя или терминал позже сужается, маскот показывается над строкой ввода. `band` всегда рисует его над строкой ввода. `status` показывает только текстовую подпись как строку состояния плагина, без изображения маскота.
- `size`: `small` (16 x 8 ячеек, по умолчанию) или `medium` (24 x 12 ячеек).
- `showLabel`: показывать или скрывать подпись рядом с маскотом (по умолчанию включено).

## Обновление плагина маскота

У маркетплейсов, кроме маркетплейса Anthropic, автообновление по умолчанию выключено, и маркетплейс не может включить его для своих пользователей. Обновляйте вручную:

```bash
claude plugin marketplace update emet-marketplace
claude plugin update emet-mascot@emet-marketplace
```

После этого перезапустите Claude Code. Чтобы обновлялось само, выполните `/plugin`, откройте вкладку **Marketplaces**, выберите `emet-marketplace` и нажмите **Enable auto-update**. Каждый пользователь делает это один раз на своей машине. Об основном плагине см. также [Обновление emet](update-emet.md).

## Phase file

CLI emet записывает `.emet/phase.json` в репозитории по ходу запуска, а маскот опрашивает его примерно раз в две секунды. Файл старше окна свежести игнорируется, поэтому упавший запуск не оставляет устаревшую подпись.

Файл содержит `phase` (`planning`, `dispatch`, `working`, `review`, `checking`, `landing`, `done` или `failed`), `wave`, `spec`, `runId`, `updatedAt` и необязательный `outcome`. Неудачная запись никогда не приводит к сбою подкоманды, сообщившей фазу.

## Питомец в Orca

Набор питомца находится в `docs/brand/pet/emet/`: `pet.json` и `spritesheet.webp`. В настройках Orca выберите «Import .codex-pet bundle…» и укажите эту папку. Для импорта нужен `docs/brand/pet/emet/` на машине, где запущено приложение Orca, поэтому скопируйте папку туда, если Orca работает не там, где этот репозиторий. Пересоздайте набор командой `bun run brand:export` после изменения SVG маскота и закоммитьте результат.

## Устранение неполадок

- Нет маскота: выполните `claude plugin list`, проверьте, что `emet-mascot` включён, затем перезапустите Claude Code.
- Нет подписи: проверьте, что `.emet/phase.json` существует и недавно обновлялся.
