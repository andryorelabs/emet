## 0.4.0

2026-11-06

### Добавлено

- Параметр `position` у `emet-mascot` (`pane`, `band` или `status`); `pane` —
  значение по умолчанию, при невозможности закрепления используется полоса.
- Раздел «Mascot (optional)» в README.

### Изменено

- Кадры `emet-mascot` привязываются к шести цветам маскота вместо
  размытия при изменении размера, поэтому пиксельная графика чёткая в терминале.
- `emet-mascot` 0.2.0: значение `size` по умолчанию теперь `small`.
- `docs/how-to/orca-pet.md` теперь называется `docs/how-to/mascot.md` и описывает мод
  и питомца Orca.

## 0.3.0

2026-11-05

### Добавлено

- Команды плагина `/emet:init` и `/emet:doctor` запускают `emet init` и
  `emet doctor .` внутри Claude Code и кратко излагают результат.
- `emet doctor` предупреждает о хуках `forge guard` и `emet guard` в
  `~/.claude/settings.json`, бинарного файла которых больше нет, и выводит
  команду, которая сначала делает резервную копию, а затем удаляет их через `jq`. Файл он никогда не правит.
- Основы маскота: phase-файл, набор питомца, конечный автомат
  мода, остальные записыватели фаз и растровые кадры.
- `emet-mascot` — необязательный плагин, который показывает пиксельного маскота над строкой ввода
  и отражает сессию и фазу запуска `emet`. Он включён в
  маркетплейс, с руководством по питомцу Orca и ADR-0016.

### Исправлено

- Плагин больше не предоставляет сломанную дублирующую команду `/emet:emet`;
  `commands/` закреплён за `run.md`, `init.md` и `doctor.md`.
- Следующая волна теперь запускается через `/emet:run` — команду, которую
  регистрирует плагин.

### Изменено

- Репозиторий переехал в организацию GitHub `andryorelabs`. Загрузки релизов,
  бейджи README и URL для клонирования теперь указывают на
  `andryorelabs/emet`; старые URL `AndryOre/emet` по-прежнему перенаправляют.
- Автономные установки переименовывают `/emet` в `/emet:run`, как и плагин.
  `install.sh` теперь устанавливает `commands/run.md`, `init.md` и `doctor.md` в
  `~/.claude/commands/emet/`, поэтому `/emet:run`, `/emet:init` и `/emet:doctor`
  доступны и без плагина. Старый `~/.claude/commands/emet.md` удаляется,
  если не был изменён; изменённая копия сохраняется и указывается в
  итоговой сводке установки.

## 0.2.0

2026-11-05

### Изменено

- Проект переименован из claude-forge в emet: CLI называется `emet`,
  команда — `/emet`, агенты — `emet-worker` и `emet-reviewer`, а
  README получил новый бренд. Существующие установки и репозитории продолжают работать:
  устаревшие имена (`forge.config.json`, `.forge/`, `docs/agents/forge.md`,
  `FORGE_*`) по-прежнему читаются с уведомлением, а `emet migrate` переводит репозиторий на
  новые имена.

### Добавлено

- `install.sh` работает без Bun: он устанавливает шим автономного бинарного файла как
  `~/.local/bin/emet`, переписывает плейсхолдеры плагина в копируемых промптах,
  устанавливает `commands/run.md` как `~/.claude/commands/emet.md` и принимает
  `shasum -a 256` вместо `sha256sum`.
- README описывает реальные требования, оба способа установки и
  порядок: сначала `/setup-matt-pocock-skills`, затем `emet init`.
- Руководство для агентов (`AGENTS.md`), доменный глоссарий (`GLOSSARY.md`) и
  записи архитектурных решений в `docs/adr/`.
- Локальный markdown-трекер по соглашению `.scratch/` с CLI `emet tracker`
  (`create-spec`, `create-ticket`, `frontier`, `set-state`, `comment`,
  `close`) и поддержкой локального режима в `emet validate`, `preflight` и `doctor`.
- `landing.mode` (`pr` или `merge`) и `emet land`, который приземляет волну как одно
  локальное слияние без PR; `emet cleanup` и `emet status` сравнивают с локальным trunk
  в режиме merge.
- Автономные бинарные файлы `emet`, `emet --version`, поддержка macOS в CI и в
  тормозе по дереву процессов и памяти, а также манифесты плагина с шимом `bin/emet`.
- Контракт навыков с `emet skill-path` и расширенный `emet doctor`, охватывающий
  навыки, глоссарий, устаревшие элементы и двойные установки.
- Не зависящие от языка `emet init` и `emet map` для репозиториев JS, Go, Rust и Python.
- ADR-0007 – ADR-0011.
- Указатель документации, карта кода архитектуры, устранение неполадок по симптомам,
  более богатый шаблон PR и `emet/AGENTS.md` с правилами только для времени выполнения.

### Изменено

- `gh` нужен только если `tracker.kind` равен `github` или `landing.mode` равен
  `pr`.
- `emet init` больше не выбирает локальный трекер по умолчанию.
- ADR-0004 изменён: волна приземляется как один PR или одно локальное слияние.

## 0.1.0

2026-11-03

### Добавлено

- Глобальная команда `/forge`: интервью, спецификация, тикеты, одно одобрение, затем
  параллельные агенты в worktree, которые без присмотра реализуют, тестируют и сливают функциональность.
- CLI `forge` с подкомандами `init`, `doctor`, `preflight`, `selftest`, захваты, слоты,
  гейты, проверки передачи, результаты и метрики.
- Агенты `forge-worker` и `forge-reviewer`.
- Трекеры для Linear и GitHub Issues.
- Конфигурация для каждого репозитория через `forge.config.json`.
- `install.sh`, который устанавливает CLI, команду и агентов.
